# travel-budget-planner
A Python travel budget planner that converts currencies, estimates daily spending, tracks expenses, compares two trips, warns about public holidays, and exports budget records.

## Features
- Currency conversion between any two three-letter ISO currency codes
- Daily spending limit and trip budget estimation
- Public holiday warnings for selected travel dates and country codes
- Expense tracking with CSV/JSON export
- Trip comparison between two destinations
- AI-powered budget advice with a fallback heuristic

## Run
Install dependencies and run the Streamlit app:

```bash
pip install streamlit requests
streamlit run app.py
```
